1. Signing in

  1. Open your site address followed by /admin (e.g. www.yourdomain.com/admin).
  2. Enter your username (or email) and password, then click Sign in.
Inactivity lock. For security, if you don't move the mouse or press any key for the configured time (15 minutes by default), the screen locks. Press any key and unlock it by entering your PIN (set when your user was created). You will land exactly where you left off.
Dark mode. At the top of the sidebar there is a moon/sun button to switch between light and dark themes. Your choice is remembered in that browser, and the login screen respects it too.
Signing out. Always use Sign out in the sidebar menu. If you just close the tab, the session stays open until it expires.

2. The dashboard

On sign-in you will see the main dashboard with:

  • Summary cards: pages, submissions, media, etc.
  • A weekly activity chart.
  • The latest form submissions (contact messages).

Global search

At the top there is a search field that finds pages, media files, products and gallery images as you type. Press Enter to open the first result or Esc to close.

Submission notifications

The Submissions menu shows a red counter with unread contact messages; the browser notifies you with a pop-up when a new one arrives (no page reload needed).

3. Pages EDITOR

Pages are the foundation of the site: every main navigation entry corresponds to a page.

Creating a page

  1. Sidebar → Pages → New page button.
  2. Enter the title. The slug (the web address) is generated automatically from the title; you can change it if needed.
  3. Choose the type:
    • Normal: free content with the visual editor.
    • Template: a predefined structure with specific fields (contact, data sheets, etc.).
    • Module: the page displays the content of an installed module (Gallery, Catalog).
  4. Write the content with the editor. To insert images use the editor's own image button: the media library opens and the image stays linked to it.
  5. In the SEO tab you can set a title and description for search engines (if left empty, the page's are used).
  6. Status: Published (visible), Draft (saved, not published) or Hidden.
  7. Save with the button at the bottom.

Adding the page to the menu

In the same form, enable «Add to navigation menu» (the Menu card):

  • The label is the text visitors see in the menu. If left empty, the page title is used.
  • You can write a different label for each language; if left empty, the menu automatically uses the page title in that language.
  • Choose a parent menu item if it should appear as a dropdown sub-entry, and its order.
Draft or hidden pages do not appear in the menu, even with the checkbox enabled. Publishing them makes them appear automatically.

Versions and restore

Every time you edit a page, the system keeps a copy of the previous version (last 20). From the page list, the versions button lets you see the changes word by word and restore a previous version if something went wrong.

Editing or deleting

From the page list: pencil icon to edit, trash icon to delete (asks for confirmation; deleting a page also removes it from the menu).

4. Menus EDITOR

In Menus you manage the whole navigation bar structure: site pages and custom links (to other websites, PDFs, etc.).

Creating or editing an item

  1. Click Add item (or the pencil on an existing one).
  2. Link to page: pick the page from the dropdown — the URL resolves automatically, even translated.
  3. Or leave the page on «None» and enter a custom URL (https://… or an internal path such as /contact). Check «New window» if it should open in a new tab.
  4. Enter the label and, if you want, its translation for each active language.
  5. Save.

Order and hierarchy

Items are reordered by dragging: drop an item onto another to make it a sub-entry (the site menu shows it as a dropdown). Click Save order when done — the button only appears if you moved something.

Icons

You can attach a small image to each menu item (it shows next to the label in the navigation bar).

5. Media library EDITOR

This is the central image library of the site. Everything you upload here can be reused in pages, gallery and catalog.

  1. Upload: drag one or more images into the drop zone (or click to pick them). Review the previews and click Upload N images. Max 5 MB per file, JPG/PNG/GIF/WebP formats.
  2. Folders: create folders to organize (e.g. «Sliders», «Team»). Only empty folders can be deleted.
  3. Edit: click an image to change its title and its alt text — important for accessibility and SEO — or to move it to another folder.
  4. Delete: from that same window, with confirmation. Careful: if the image is used on a page, it will appear broken there.
The system generates thumbnails automatically on upload: lists load fast and visitors only download the large image when they open it.

6. Gallery EDITOR

The gallery module displays image collections on the site, organized into albums.

Uploading images

  1. Gallery → Upload images.
  2. Drag in the photos and set the album (type the name: it autocompletes if it exists, otherwise it is created on upload).
  3. Click Upload (you will see the progress bar).
  4. The «Add from library» option takes images already in Media without duplicating files.

Managing

In the list you can filter by album and delete images. Images can be deactivated (they stop showing on the site without being deleted).

Translating album names

The «Translate albums» button: enter each album's name in each active language. On the site, visitors see the name in their language; the web addresses (URLs) do not change, so links never break.

The site gallery is displayed through its module page (e.g. «Gallery»). If the gallery doesn't load, check in Pages that this page exists, is of type module and is published.

7. Catalog EDITOR

Product and category management, if the module is active.

Products

  • Create: name, short and long descriptions, price and previous price (to show a discount), main image and image gallery, category, SEO.
  • Enable/disable: an inactive product is not shown on the site.
  • Import: bulk creation from a file (format indicated on that same screen).

Categories

  • With name, slug, description, image and order.
  • In the form you can enter the category name in each language (if left empty, the main name is shown).
  • Categories containing products cannot be deleted.
Products and categories on the site are displayed through the «Catalog» module page (it must exist and be published, like the gallery).

8. Templates and themes ADMIN

Templates

Predefined page structures with specific fields (for example, a «Contact» template with map and opening hours). When you create a page of type template you only fill in those fields. Templates are defined by the developer.

Themes

In Themes you activate the site's visual appearance (colors, fonts, layout). Activating one applies the change immediately. Themes are installed by the developer in public/themes/.

Modules

SUPERADMIN List of installed modules (Gallery, Catalog…) with an enable/disable switch. A disabled module disappears from the site and the sidebar without losing its data.

9. Users and roles ADMIN

RoleWhat they can do
EditorManage pages, menus, media, gallery, catalog and read submissions.
AdminAll the above + users, settings, themes and templates.
SuperadminAll the above + modules and backups.
  1. Users → New user: name, email, password, role and unlock PIN (4–6 digits, for the lock screen).
  2. From the list you can edit, deactivate or delete users.
For security, after 5 failed sign-in attempts, the account is locked for 15 minutes.

10. Settings ADMIN

Organized in tabs:

  • General: site name, default language, contact email, homepage (which page shows when entering the domain: your choice or the theme's landing) and maintenance mode.
  • SEO: general site description for search engines.
  • Social networks: profile links.
  • Company: tax and contact details (may be shown in the site footer depending on the theme).
  • Lock: minutes of inactivity before the panel screen locks.

Maintenance mode

With the switch on, visitors see a «We'll be right back» page (a 503 error, which search engines respect) while you, signed in as an admin, see and work on the site normally. Editors do NOT see the site during maintenance. To test it, use a private/incognito window.

The sitemap.xml (site map for search engines) is generated automatically and includes the versions in each language. It is available at /sitemap.xml.

11. Backups SUPERADMIN

  1. Backups → Create backup. The system packages the full database and all uploaded images into a ZIP file.
  2. Download the ZIP and keep it off the server (your computer, external drive, cloud).
  3. Delete old backups from the server once downloaded — they take up hosting space.
Restoring a backup is a developer task: it requires importing the SQL into the database and unzipping the images, plus regenerating thumbnails (thumbs:regenerate). It is not an everyday process; if needed, contact whoever maintains the site.

12. A multilingual site

The CMS is multilingual out of the box. Key concepts:

  • Default language: the one set in Settings (e.g. Spanish). Its content is served without a prefix in the URL (/quienes-somos).
  • Additional languages: visitors switch with the selector (flags) on the website; the URL carries a prefix (/en/about-us).
  • Partial translation: each field is translated independently. If a field is left empty in a language, the site automatically shows the default language's content — nothing ever breaks.
  • What can be translated: page titles and content, menu labels, album names and category names, and the modules' own texts (Gallery, Catalog…).
  • Slugs (addresses): each language has its own address per page; search engines automatically receive the relationship between languages (hreflang).
Workflow tip: write everything in the default language first, publish, and then translate page by page from their language tabs.

13. Troubleshooting

SymptomSolution
A page shows «404 not found»Check that it is published (Pages) and that the URL has no case errors.
The page doesn't appear in the menuIt must be published AND have «Add to menu» enabled in its edit form. Also check the item is active in the Menus section.
Switching language lands on a different pageEach page is linked to its translations via its slug; if a translation points to another page, review the language tabs of both.
«Site under maintenance» and can't get inGo to /admin (the panel is always reachable) and turn off maintenance mode in Settings. If you forgot your password, another admin can help.
The screen locked and I forgot my PINSign out (there is a link on the lock screen) and sign back in with username and password.
I deleted content by mistakePages: use the version history to restore. Other content: recover the latest backup with the developer's help.
I upload an image and it doesn't show on the siteCheck the format (JPG/PNG/GIF/WebP) and size (max 5 MB). In media, verify the file exists; in gallery, that the image is active and in an existing album.
The panel search doesn't find something that existsType at least 2 characters and wait half a second (it searches when you stop typing).
